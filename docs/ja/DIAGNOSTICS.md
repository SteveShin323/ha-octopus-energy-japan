# 診断情報と修復メッセージ

状態: OAuth Application 発行前のプレアルファ版

規範となる英語版の仕様は
[`docs/DIAGNOSTICS_AND_REPAIRS.md`](../DIAGNOSTICS_AND_REPAIRS.md) です。

## 不具合を報告するとき

Home Assistant の「設定 → デバイスとサービス → Octopus Energy Japan」から
**診断情報をダウンロード** し、そのファイルを GitHub の Issue に添付してください。

このファイルには、**お客さまを特定できる情報は含まれません。** 中身を確認してから
添付する必要はありません。含まれないものは次のとおりです。

- OAuth トークン
- メールアドレス、氏名、住所
- 契約番号、供給地点特定番号（SPIN）、メーター番号
- 使用量の数値、料金、残高、請求額
- エラーメッセージの本文（種類のみ記録します）

含まれるのは、連携のバージョン、どの取得方法が選ばれたか、各系列が最後に成功した
時刻、訂正の回数といった、この Home Assistant 内でしか意味を持たない識別子と
件数だけです。

ログを貼る必要はありません。ログには事業者からのメッセージが含まれることがあり、
そこにお客さまの情報が混ざる場合があります。

## 表示される修復メッセージ

いずれも **操作は不要** です。Home Assistant の中で解決できる原因ではないため、
「修復」ボタンは用意していません。状況の説明としてお読みください。

### 保存されている履歴を読み込めませんでした

保存済みデータの一部が壊れていたため、残りを守るために切り離しました。直近の
使用量は引き続き記録されます。該当月の集計と Energy Dashboard の統計は不完全に
なることがあります。

連携を削除して再追加すると、今月と前月ぶんを再取得します。Octopus Energy Japan
自体はそれより古い区間も提供しているため、より広い範囲の復元は原理的には可能ですが、
現在の連携は自動では要求しません。

### 新しい使用量が届いていません

36時間以上、新しい30分値が届いていない系列があります。30分値は数時間遅れて届くのが
通常なので、短い空白は正常です。それより長い場合は、計量データが Octopus Energy
Japan にまだ到着していないことがほとんどです。

連携は自動的に再試行し、データが届いた時点で空白を埋めます。

### 一部の取得方法が利用できません

お客さまのアカウントで利用できない取得方法があります。連携は利用可能な方法へ
自動的に切り替えるため、通常は使用量の記録が続きます。

すべての方法が挙げられている場合のみ、新しい使用量を取得できません。

### 一部のアカウント情報にアクセスできません

認可の範囲に契約情報や請求情報が含まれていません。使用量、集計、Energy Dashboard の
統計には影響しません。該当する情報のエンティティが「利用不可」のままになります。

これは異常ではなく、アカウントの権限がそうなっているという事実です。
