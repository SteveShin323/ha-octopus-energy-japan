# Energy Dashboard の統計

この連携は、Octopus Energy Japan から取得した区間使用量を Home Assistant の
外部長期統計へ変換します。

## 登録手順

**設定 → ダッシュボード → エネルギー → 電力の使用量 → 使用量を追加** を開き、
供給地点の名前が付いた統計を選択してください。例: `OEJP supply point 1-1 Import
energy`。OEJP が売電方向を提供している場合は、`… Export energy` を
**電力網へ送った電力量** に追加します。

選ぶのは **統計** です。期間エンティティ（今日・今月など）ではありません。期間
エンティティは表示用で、訂正に対応できる正式なデータは統計側です。

**料金の欄には `OEJP supply point 1-1 Import cost` を選んでください。** 単価の欄は
そのままにしてください。Home Assistant は「センサー」エンティティにしか単価を掛けず、
外部統計では計算を行わないため、入力した単価は適用されずに無視されます。料金統計が
唯一の経路で、この連携はそれを発行します。

料金は OEJP が提供する契約中の料金プランから計算します。3段階の単価とその kWh 境界、
日割りの基本料金、月ごとの燃料費調整、年ごとの再エネ賦課金 — いずれも利用者の入力は
不要です。

**あくまで良い概算で、請求書そのものではありません。** 実際の請求書と照合すると
請求額の104%でした。理由は2つあり、いずれも現状では避けられません。請求書は深夜すぎの
検針時刻までを1期間としますが、この計算の段階単価は日本時間の暦月でリセットされます。
また OEJP は**当月分**の燃料費調整単価のみを公開しており、それ以前の月の区間には
適用できません。詳細は [`ENERGY_STATISTICS.md`](../ENERGY_STATISTICS.md)（英語）に
記載しています。

累積値のメーターセンサーは意図的に用意していません。OEJP は30分値を数時間
遅れて公開し、請求期間が締まると訂正します。そのようなデータから累積センサーを
作ると、遅れるか値が逆行するかのどちらかになり、ダッシュボードはその両方を
記録してしまいます。

### 選択画面に表示される名前

選択画面には統計の名前だけが表示されるため、名前は供給地点デバイスに合わせて
います。契約番号・供給地点特定番号・住所は含みません。供給地点が2つある場合は
`OEJP supply point 1-1` と `OEJP supply point 1-2` のように、デバイスと同じ
表記になります。

## 提供する統計

- 供給地点ごとの買電量（import energy、kWh）
- OEJP が売電方向を提供する場合の売電量（export energy、kWh）

統計は1時間単位の使用量と累積値を持ちます。累積値の起点は、この連携が
ローカル ledger に保存している最も古い reading です。電力量計の生涯値では
ありません。

OEJP が返す公式コストの内部モデルはありますが、公開しません。実際の請求書と
照合したところ、実際の料金プランを再現しないことが確定しています。詳細は
[契約・料金プラン・請求情報](CONTRACT_AND_BILLING.md)を参照してください。
利用者が入力した単価による単純な料金推定は Energy Dashboard へ登録しません。

## 遅延および訂正

OEJP の30分 reading はリアルタイム値ではなく、遅れて追加または訂正される
場合があります。この連携は存在しない reading をゼロとして作成しません。
遅延 reading が届いた場合は、対象時刻とそれ以降の累積値を再計算します。

API が以前の reading を削除した場合は、影響する供給地点・方向の統計だけを
Home Assistant Recorder 上で再構築します。再起動、同じデータの再取得、訂正の
再処理後も同じ結果になるよう設計されています。

## プライバシー

統計 ID には、Home Assistant ごとに異なるローカル HMAC 識別子を使用します。
Account number、SPIN、Supply Point ID、住所、メールアドレス、OAuth token は
統計 ID、名称、ログ、診断情報へそのまま表示しません。外部 telemetry は
送信しません。

## リリース後の設定

OAuth 対応版の正式リリース後、Home Assistant の
**設定 → ダッシュボード → エネルギー**から、
`octopus_energy_japan` の買電または売電統計を選択します。具体的な画面手順は
リリース前のクリーンインストール検証後に追記します。

実装上の規範仕様は英語版
[`../ENERGY_STATISTICS.md`](../ENERGY_STATISTICS.md) を参照してください。
