# Code of Conduct

## Our commitment

This project exists so people can see their own energy data. Everyone is welcome to
use it, report problems with it, and improve it, regardless of experience, identity,
nationality, or language.

## Expected behaviour

- Be direct about code and gentle about people. Review the change, not the author.
- Assume a report is genuine. Someone taking the time to describe a problem is
  helping.
- Japanese and English are both welcome in issues and discussions. Reply in the
  language the reporter used if you can; a machine translation with a note is
  better than silence.
- Explain a rejection. "Out of scope because it would require storing a client
  secret" is useful; "no" is not.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sexualised content,
deliberate intimidation, publishing someone's private information, and sustained
disruption.

## Privacy in public

Never post another person's account number, supply-point number, address, or
tokens, and take care not to post your own. Diagnostics downloads are designed to
be safe to attach; raw logs and screenshots are not. A maintainer may edit or
delete a comment that exposes personal data without waiting for permission.

## Scope

Applies in this repository's issues, pull requests, discussions, and commit
messages, and to anyone representing the project elsewhere.

## Reporting

Report conduct concerns privately through the contact in
[`SECURITY.md`](SECURITY.md). Reports are handled confidentially. The maintainer
will not act on a report about themselves; escalate to GitHub Support if that
happens.

## Enforcement

Depending on severity: a private word, a public correction, deleting the content, a
temporary block, or a permanent ban. The reasoning will be stated, unless doing so
would expose the reporter.
